# 实验五：卷积神经网络 LeNet 实现与特征图可视化
## 一、实验目的
掌握 PyTorch 中卷积神经网络的基本搭建方法；

理解 LeNet-5 的网络结构，包括卷积层、池化层、全连接层的作用；

学会在 MNIST 手写数字数据集上完成模型的训练与测试；

学会提取并可视化卷积层的特征图，直观理解卷积层对图像特征的提取过程。
## 二、实验环境
编程语言：Python

深度学习框架：PyTorch

数据集与工具：torchvision

可视化工具：Matplotlib

计算设备：自动选择 CUDA 或 CPU
